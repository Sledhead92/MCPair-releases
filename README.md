# MCPair releases

Installers and updates for MCPair, a desktop app that keeps the MCP servers used by Claude Desktop, Claude Code, and Codex in one place, and applies them to each client with a diff and a backup.

## Download

Get the latest version from [Releases](https://github.com/Sledhead92/MCPair-releases/releases/latest):

- **Windows:** `MCPair-Setup-<version>.exe`. SmartScreen may warn on the first install because the installer is not signed yet. After that, MCPair updates itself.
- **macOS:** the `.dmg` for Apple silicon (`arm64`) or Intel (`x64`). The app is not signed yet, so right-click it and choose Open the first time. MCPair tells you when an update is out and links here.
- **Linux:** the `.AppImage`. MCPair updates itself.

## Feedback and bug reports

Use **Feedback** in the app, or open an issue here. Please don't include tokens, keys, passwords, private URLs, or config file contents. Describe the problem instead.

This repository holds only release files. The source code is not public.
